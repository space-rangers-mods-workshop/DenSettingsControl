## 📖 Description

**DenSettingsControl** adds a panel to the space screen that lets you change the party's **difficulty** and its **fine (advanced) settings** right while playing — no restart needed.

Two buttons appear in the upper-left corner of the space screen: one opens the advanced adjustments, the other the difficulty. The mod can be enabled or disabled during a party.

## 📦 Installation instructions

### 🤖 Automatic — Mod Organizer 2

The easiest way is to install the mod through **Mod Organizer 2** using the plugin for Space Rangers HD: A War Apart:

- [Mod Organizer 2 plugin for Space Rangers HD](https://www.nexusmods.com/spacerangersawarapart/mods/57)

Download the mod with MO2 mod manager and deploy it — the plugin places the mod in the correct `Mods\` folder for you.

### ✋ Manual

1. Make sure the game loads mods from its `Mods\` folder.
2. Download the latest release archive from the
   [GitHub releases page](https://github.com/space-rangers-mods-workshop/DenSettingsControl/releases/latest)
   (or the [Nexus Mods page](https://www.nexusmods.com/spacerangersawarapart/mods/62)).
3. Unpack the archive into the game's `Mods\` folder so that the mod folder ends up at:
   ```
   <game root>\Mods\Den\DenSettingsControl
   ```
   (The folder must contain `ModuleInfo.txt` at its root — do not nest it an extra level down.)
4. Launch the game. The panel's buttons appear on the space screen.

To remove the mod, delete the `DenSettingsControl` folder.

## ✨ Main features

- Change the party's **difficulty** during play.
- Change the party's **fine (advanced) settings** during play.
- Can be enabled or disabled during a party.
